# Герои — структура данных

Все герои (и ещё не завербованные поселенцы) описаны в `game/data/characters.json`,
массив `"characters"`.

## Добавить нового героя

1. Скопировать блок существующего персонажа (например, `char_1`) в массиве
   `"characters"`.
2. Поменять `"id"` (должен быть уникальным), `"name"`, характеристики
   (`health`, `strength`, `endurance`, `agility`, `intelligence`) и `"avatar"`.
3. Задать анимации в `"sprites"` — самый простой вариант — оставить те же
   пути, что и у скопированного героя (тогда герой временно выглядит как
   базовый), и подменить их на свою папку `game/assets/characters/<id>/...`,
   когда появится арт.

## Схема `"sprites"`

```json
"sprites": {
  "idle": ["путь_кадр0.png", "путь_кадр1.png", "..."],
  "run": ["путь_кадр0.png", "..."],
  "afk": ["путь_кадр0.png", "..."],
  "attack": ["путь_кадр0.png", "..."],
  "examine": ["путь_кадр0.png", "..."]
}
```

Если для персонажа есть отдельные кадры бега влево/вправо (а не один набор,
который движок отражает по горизонтали сам), вместо `"run"` указываются
`"runLeft"` и `"runRight"` — движок сам определяет "направленного" персонажа
по наличию `runLeft` (см. `Game._spriteSetFor` / `_renderCharacters`).

Число кадров в любой анимации не ограничено — можно ставить как один кадр
(тогда поза статична), так и десяток.

Спрайты загружаются один раз на персонажа при старте игры
(`Game._loadCharacterSprites`, `Game._buildSpriteSet`) — код трогать не нужно,
всё берётся из этого файла.
